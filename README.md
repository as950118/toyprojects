# toyprojects

2025년에 진행한 백엔드 토이프로젝트 모음. 각 폴더는 원래 별도 저장소였고, 커밋 히스토리를 유지한 채 합쳤습니다.

| 폴더 | 내용 | 원래 저장소 |
|---|---|---|
| [`rag/`](rag/) | 한국어 문서 RAG 파이프라인 (청킹 → 임베딩 → FAISS → Ollama) | `rag-toyproject` |
| [`lms/`](lms/) | LMS(학습 관리 시스템) Django 백엔드 + React 프론트엔드 | `lms-toyproject` |
| [`search/`](search/) | 회사 정보/태그 다국어 검색 REST API (PostgreSQL, Docker) | `search-toyproject` |
| [`shopping/`](shopping/) | 쇼핑몰 상품 관리 API (할인/쿠폰 가격 계산, MySQL, pytest) | `shopping-toyproject` |
| [`portfolio-manage/`](portfolio-manage/) | 잔고·위험 성향 기반 포트폴리오 자문 백엔드 API | `portfolio-manage-toyproject` |
